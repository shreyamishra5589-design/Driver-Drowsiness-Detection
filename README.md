# Driver Drowsiness Detection System

A real-time driver drowsiness detection project using Deep Learning, TensorFlow/Keras and OpenCV.

## Overview
This project aims to detect driver drowsiness through eye monitoring and a trained deep learning model. It focuses on identifying signs of fatigue to support road safety.

## Tech Stack
- Python
- TensorFlow / Keras
- OpenCV
- Jupyter Notebook
- Haar Cascade Classifier

## Project Structure
```text
Driver-Drowsiness-Detection/
│
├── driver_drowsiness_model.keras
├── haarcascade_eye.xml
├── realtime.ipynb
└── README.md
```

## Features
- Real-time eye detection
- Deep learning-based detection
- Webcam-based monitoring

## Getting Started
1. Clone this repository.
2. Install the required Python dependencies.
3. Open `realtime.ipynb` in Jupyter Notebook.
4. Execute the notebook cells.
